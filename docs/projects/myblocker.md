# MyBlocker

> *A simple Chrome extension to block distracting websites locally in your browser*

![Extension Preview](../assets/blocker.jpg)

## Overview

- A lightweight, fully local site blocker — no accounts or servers; the block list lives in the browser's own extension storage
- **Block the current site** in one click
- **Add and manage custom domains**
- **Enable/disable sites** with checkboxes

## Tech Stack

| Layer | Tools |
|---|---|
| **Logic** | Vanilla JavaScript, Chrome Extension APIs |
| **Storage** | `chrome.storage.local` |

## Skills Developed

- Browser extension architecture (manifest, popup, background scripts)
- Persistent client-side state
