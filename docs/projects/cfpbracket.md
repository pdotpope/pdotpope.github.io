# Bracket Generator

> *An interactive web app for building and exporting College Football Playoff brackets*

[:material-web: Live Site](https://cfp-bracket.pdot.dev){ .md-button .md-button--primary target="_blank" rel="noopener" }

![Site Preview](../assets/bracket.gif)

## Overview

<!-- TODO: confirm description; mention what GitHub Actions automates -->

- A static front-end app hosted on GitHub Pages for filling out a playoff bracket in the browser and exporting it as an image
- **Interactive bracket** that advances teams as picks are made
- **Export to multiple image formats**
- **Automated deploys** via GitHub Actions

## Tech Stack

| Layer | Tools |
|---|---|
| **Frontend** | HTML, CSS, JavaScript |
| **Hosting / CI** | GitHub Pages, GitHub Actions |
| **Assistant** | Claude Sonnet |

## Skills Developed

- Interactive front-end development
- Bracket logic and state management
- Client-side image generation
